Key references

  • Category Theory in Context, Emily Riehl (2016) Riehl develops the category theory used throughout the slides.
  • Category Theory for AGI, Sridhar Mahadevan (Spring 2026) The seminar page provides the companion syllabus and lecture materials.
  • Categories for AGI, Sridhar Mahadevan (2026) Mahadevan’s course text studies category-theoretic formulations of artificial general intelligence.
  • Universal Decisions with Kan Extensions, Sridhar Mahadevan Mahadevan formulates decision problems through left and right Kan extensions.
  • DisCoPy DisCoPy is a Python toolkit for computing with string diagrams.
